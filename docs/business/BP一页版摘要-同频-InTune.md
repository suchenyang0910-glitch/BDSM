# 同频 InTune BP 一页版摘要

更新时间：2026-07-31

## 项目一句话

同频 InTune 是一个面向成年人的垂直兴趣直播社区，强调平等、尊重、真实表达与高质量连接。

## 项目机会

当前主流直播平台大多以刺激分发、短期转化和流量收割为核心，虽然能形成交易，但难以建立长期品牌价值和稳定关系留存。

垂直兴趣人群真正缺少的，不是内容数量，而是：

- 被认真对待的表达空间
- 有边界感和秩序感的互动环境
- 直播之外可持续沉淀关系的社区结构

## 解决方案

同频采用“直播 + 社区 + 消息 + 会员 + 创作者成长体系”的产品结构，形成内容分发与关系沉淀双飞轮。

核心页面：

- 首页：推荐内容与品牌入口
- 社区：动态、话题、预约与关系沉淀
- 消息：互动召回与系统触达
- 我的：身份、资产、会员、认证与创作者工具

## 冷启动策略

同频前期优先解决供给问题，而非盲目拉新。

供给策略分三层：

- 种子主播引入
- 数字化内容补位
- 外部合作内容引入

增长策略分两阶段：

- 前期：抖音、小红书等平台内容种草 + 小额投放测试
- 后期：创作者带粉 + 社区沉淀 + 消息召回

## 商业模式

前期收入来源：

- 钱包充值
- 基础会员订阅
- 活动与主题运营

中期扩展：

- 创作者成长服务
- 品牌合作
- 社区活动合作

## 技术方案

采用“购买成熟二开代码 + 定制开发改造”的方式快速上线。

开发周期：

- 技术开发、验收到完成上线，预计 1 个月

开发预算：

- 27,000 USDT

## 项目结论

同频不是一个短期刺激型平台项目，而是一个围绕高质量关系、真实表达与长期留存构建的垂直社区型直播平台机会。
