# 文档目录说明

本仓库的 Markdown 文档已按用途归档到 `docs/` 下，便于持续维护与查找。

## 分类约定

- `docs/prd`
  - 页面 PRD、产品资料、各模块需求文档
- `docs/tasks`
  - Trae 任务书、阶段调整任务、增量开发任务书
- `docs/architecture`
  - 技术 PRD、数据模型、API 契约、后台规划、支付架构文档
- `docs/deployment`
  - 上线说明、部署检查清单
- `docs/business`
  - 商业计划书、路演材料、启动与融资相关文档

## 当前整理原则

- 仅移动 Markdown 文档，不改动业务代码目录结构
- 保留原文件名，降低历史追溯成本
- 对已知文档内路径引用做最小修正，避免搬迁后失效
