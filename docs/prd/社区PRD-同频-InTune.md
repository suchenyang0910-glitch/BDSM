# 同频 InTune 社区 PRD

更新时间：2026-07-28

## 1. 页面定位

页面名称：社区

页面角色：

- 用户表达主场
- 关系沉淀主场
- 话题与圈层承接页

一句话目标：

让用户从观看走向表达，从单次停留走向持续互动。

## 2. 页面目标

1. 提供动态表达能力
2. 提升评论、收藏、关注等互动行为
3. 支撑同城、话题、兴趣圈层形成关系沉淀
4. 为直播之外提供稳定停留场景

## 3. 目标用户

- 有浏览和互动意愿的用户
- 想发布动态的表达型用户
- 希望建立圈层关系的活跃用户

## 4. 页面结构

1. 顶部 Tab 导航
2. 话题入口区
3. 动态流
4. 发布入口
5. 推荐关注区

## 5. 模块说明

### 5.1 顶部 Tab 导航

建议 Tab：

- 最新
- 热门
- 关注
- 同城
- 话题

交互逻辑：

- 点击 Tab -> 切换对应内容流

### 5.2 话题入口区

展示内容：

- 本周话题
- 兴趣标签
- 城市标签

交互逻辑：

- 点击话题或标签 -> 进入话题聚合页

### 5.3 动态流

内容类型：

- 文本
- 图片
- 短视频
- 预约信息
- 活动互动

卡片字段：

- 头像
- 昵称
- 标签
- 发布时间
- 正文
- 媒体内容
- 点赞、评论、收藏

交互逻辑：

- 点击正文或媒体 -> 进入动态详情
- 点击头像 -> 用户主页
- 点击点赞 -> 点赞
- 点击评论 -> 评论层
- 点击收藏 -> 收藏
- 点击更多 -> 举报 / 拉黑 / 不感兴趣

### 5.4 发布入口

支持内容：

- 文字
- 图片
- 短视频
- 标签
- 位置
- 预约信息

交互逻辑：

- 点击发布入口 -> 发布页
- 发布成功 -> 返回社区流或动态详情

### 5.5 推荐关注区

展示内容：

- 推荐用户
- 推荐创作者
- 同城同好

交互逻辑：

- 点击进入用户主页
- 点击 `关注` -> 完成关注

## 6. 页面流程

浏览流程：

```text
进入社区页
  ->
浏览动态流
  ->
互动或查看详情
```

发布流程：

```text
社区页
  ->
发布入口
  ->
编辑内容
  ->
发布成功
  ->
返回社区流或动态详情
```

## 7. 页面状态

支持状态：

- 默认状态
- 加载中
- 空状态
- 错误状态
- 无关注状态

空状态文案建议：

- 还没有内容，去看看大家在聊什么

无关注文案建议：

- 先关注一些同频的人，动态会更精彩

## 8. 核心指标

- 动态浏览量
- 动态发布率
- 点赞率
- 评论率
- 收藏率
- 关注转化率
- 社区停留时长

## 9. 功能优先级

P0：

- 动态流浏览
- 点赞 / 评论 / 收藏
- 发布动态
- 举报

P1：

- 话题页
- 关注流
- 推荐关注区

P2：

- 同城流
- 分享能力

## 10. 与其他页面关系

- 跳转动态详情
- 跳转用户主页
- 跳转话题页
- 跳转发布页
- 跳转直播间（从动态中的直播预约或内容入口）
