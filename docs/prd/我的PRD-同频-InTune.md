# 同频 InTune 我的 PRD

更新时间：2026-07-28

## 1. 页面定位

页面名称：我的

页面角色：

- 用户身份中心
- 资产与权益中心
- 创作者工具入口
- 设置与安全中心

一句话目标：

让用户高效管理自己的身份、内容、资产与权限。

## 2. 页面目标

1. 汇总用户身份信息
2. 提供钱包、会员、收益等资产入口
3. 提供主播认证和房间管理等创作者工具
4. 提供设置、隐私、安全等管理能力

## 3. 目标用户

- 普通浏览用户
- 活跃互动用户
- 创作者 / 主播
- 高价值付费用户

## 4. 页面结构

1. 顶部个人身份区
2. 资产与权益区
3. 创作者工具区
4. 我的内容区
5. 服务与设置区

## 5. 模块说明

### 5.1 顶部个人身份区

展示内容：

- 头像
- 昵称
- 个性签名
- 粉丝数、关注数、收藏数
- 兴趣标签

交互逻辑：

- 点击头像或昵称 -> 进入个人主页
- 点击 `编辑资料` -> 进入资料编辑页

### 5.2 资产与权益区

展示内容：

- 钱包
- 会员
- 等级
- 收益

交互逻辑：

- 点击 `钱包` -> 钱包页
- 点击 `会员` -> 会员页
- 点击 `收益` -> 收益页

### 5.3 创作者工具区

展示内容：

- 主播认证
- 房间管理
- 开播预告
- 数据概览

状态说明：

- 未认证：显示 `申请认证`
- 已认证：显示 `进入主播中心`

交互逻辑：

- 点击 `主播认证` -> 认证页
- 点击 `房间管理` -> 房间管理页
- 点击 `开播预告` -> 预告设置页

### 5.4 我的内容区

展示内容：

- 我的动态
- 我的预约
- 我的回放
- 我的收藏

交互逻辑：

- 点击任一入口 -> 对应列表页

### 5.5 服务与设置区

展示内容：

- 帮助与反馈
- 社区规则
- 隐私设置
- 安全中心
- 黑名单

交互逻辑：

- 点击对应入口 -> 对应详情或设置页

## 6. 页面流程

主流程：

```text
进入我的页
  ->
查看身份信息与资产入口
  ->
选择动作
  ->
进入钱包 / 会员 / 认证 / 房间管理 / 设置 / 内容列表
```

创作者流程：

```text
我的页
  ->
主播认证
  ->
提交资料
  ->
审核通过
  ->
进入主播中心
```

## 7. 页面状态

支持状态：

- 默认状态
- 未登录状态
- 未认证状态
- 已认证状态
- 加载中
- 错误状态

未登录文案建议：

- 登录后即可查看你的内容与权益

未认证文案建议：

- 完成认证后即可开启创作者功能
