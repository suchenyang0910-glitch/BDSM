## 1. 产品定位

产品名称：

- 中文：同频
- 英文：InTune

一句话定位：

一个让真实表达发生连接的垂直兴趣直播社区。

产品设计原则：

- 先关系，再消费
- 先秩序，再增长
- 先品牌感，再刺激感
- 先推荐效率，再功能堆叠

## 2. 竞品页面结构拆解

竞品整体判断：

该竞品本质上是一个以强刺激内容分发、充值转化、主播消费和活动促销为核心的变现型直播产品，而不是强调关系质量和长期社区归属的直播社区。

其底层产品逻辑可以概括为：

高刺激曝光 -> 点击进入 -> 停留围观 -> 充值买币 -> 打赏或解锁 -> 回放复购

### 2.1 首页结构拆解

- 顶部频道导航：关注、首页、直播、回放、短视频、搜索
- Banner 活动位：推广合作、周年庆等高曝光运营位
- 直播推荐区：独家直播、精选主播、新人主播
- 分类区：按内容刺激标签划分的频道入口
- 底部导航：玩物、社区、消息、我的

### 2.2 直播页结构拆解

直播页采用双列流内容瀑布式结构，以封面图和标题为主导，辅以在线人数、热度、标签、连麦状态等元素。

### 2.3 回放与短视频结构拆解

回放页与短视频页承担二次转化功能，帮助用户在非直播时段继续消费内容。

### 2.4 社区页结构拆解

社区页使用动态流承接用户内容发布，包含最新、最热、新人等标签，带城市和互动信息。

### 2.5 消息页结构拆解

消息页按系统通知、钱包服务、官方助手、点赞收藏、评论关注等进行分类。

### 2.6 我的页结构拆解

我的页是用户资产与身份体系中心，包含个人资料、会员等级、钱包余额、活动中心、购买记录、收益、主播认证、房间管理等入口。

### 2.7 钱包页结构拆解

钱包页承担最强商业化任务，核心结构为：

- 会员或等级卡面
- 余额展示
- 多档充值套餐
- 推荐档位和赠送机制
- 一键充值按钮

## 3. 我们该学什么

### 3.1 可学习的结构能力

- 四栏底部导航足够成熟，用户理解成本低
- 首页、社区、消息、我的职责划分清楚
- 直播、回放、短视频承担不同消费任务，结构上值得借鉴
- 钱包、会员、认证、收益形成完整商业闭环
- 活动位、专题位、横幅位、弹窗位形成强运营阵地

### 3.2 可学习的运营能力

- Banner 位用于承接阶段性活动和招商合作
- 消息中心分类明确，便于做唤醒和召回
- 钱包页通过档位设计和推荐位提高转化
- 我的页整合用户身份、资产、权限和内容管理
- 回放和短视频补足直播供给不稳定问题

### 3.3 可学习的增长能力

- 新人主播专区利于冷启动供给建设
- 精选主播与热门分层利于用户决策
- 平台活动中心统一承载节点运营
- 推广合作模块说明其重视渠道与私域增长

## 4. 我们该避开什么

### 4.1 避免视觉气质失控

不要采用：

- 过度高饱和粉紫霓虹视觉
- 满屏促销和刺激文案
- 夜场化、诱导化、廉价感强的视觉包装

### 4.2 避免产品逻辑跑偏

不要把首页做成纯刺激内容货架，不要让用户一进入就只剩下消费冲动，而看不到品牌主张、社区氛围和关系价值。

### 4.3 避免文案气质下降

不要使用：

- 强煽动
- 强暗示
- 强消费诱导
- 身份物化
- 冒犯式标签

### 4.4 避免社区沦为附属页

如果社区只是给内容导流，用户关系会非常浅。对同频来说，社区必须是“连接发生的主场”之一，而不是可有可无的补充页。

### 4.5 避免把商业化做成唯一路径

钱包和会员可以强，但不能压过品牌和关系价值。

## 9. 同频产品 PRD 框架

### 9.1 产品背景

同频 InTune 是一个面向成年人的垂直兴趣直播社区，强调平等、尊重、真实表达、边界意识与高质量连接。

### 9.2 用户角色定义

1. 浏览型用户：快速看到适合自己的内容
2. 互动型用户：关注、评论、收藏、预约、参与话题
3. 创作者或主播：开播、管理内容、积累粉丝、建立个人空间
4. 高价值用户：更稳定内容体验、更强权益、更高效发现

### 9.3 首页 PRD

页面目标：

- 建立品牌第一印象
- 帮助用户快速找到适合自己的内容
- 承接直播、社区、活动和预约入口

页面结构：

1. 顶部品牌导航栏
2. 今日推荐区
3. 主题直播区
4. 社区动态区
5. 创作者推荐区
6. 活动与预约区
7. 规则与信任入口

关键指标：

- 首页曝光人数
- 首页卡片点击率
- 直播间进入率
- 关注转化率
- 预约转化率
- 首日观看时长

### 9.4 社区 PRD

页面目标：

- 承担用户内容表达与关系沉淀
- 提升不开播时段的用户停留与互动
- 形成兴趣圈层、同城和话题归属感

页面结构：

1. 顶部 Tab 导航
2. 话题入口区
3. 动态流
4. 发布入口
5. 推荐关注区

关键指标：

- 动态发布率
- 点赞率
- 评论率
- 收藏率
- 关注转化率
- 社区停留时长

### 9.5 消息 PRD

页面目标：

- 聚合用户所有回访信号
- 提升互动回流效率
- 连接系统消息、服务消息和关系消息

页面结构：

1. 顶部消息分类快捷入口
2. 官方与服务消息区
3. 私信或关系消息区
4. 开播提醒与活动提醒区

关键指标：

- 消息到达率
- 消息点击率
- 回访率
- 评论回复率
- 开播提醒打开率

### 9.6 我的 PRD

页面目标：

- 成为用户身份中心
- 汇总个人资产、权益、设置和内容管理
- 承担钱包、会员、认证与创作者工具入口

页面结构：

1. 顶部个人身份区
2. 资产与权益区
3. 创作者工具区
4. 我的内容区
5. 服务与设置区

关键指标：

- 钱包点击率
- 会员开通率
- 认证申请率
- 内容管理使用率
- 设置页访问率

## 10. 同频产品原型说明书

本说明书用于将 PRD 进一步落到页面交互、按钮、状态和页面跳转，供产品、设计、研发对齐。

### 10.1 首页原型说明

#### 页面目标

- 帮助用户 5 秒内理解平台气质
- 帮助用户 10 秒内找到第一条感兴趣内容
- 帮助用户在 1 分钟内完成一次进入直播间、关注或预约

#### 页面模块与交互

模块 A：顶部品牌栏

- 左侧：Logo / 同频字样
- 中间：可选 slogan 或轻提示
- 右侧：搜索、活动、消息按钮

按钮交互：

- 点击 `搜索` -> 进入搜索页
- 点击 `活动` -> 进入活动中心页
- 点击 `消息` -> 进入消息页

状态说明：

- 未读消息时，消息按钮右上角显示红点
- 有活动时，活动按钮可显示轻角标

模块 B：今日推荐卡片

- 卡片字段：封面、标题、主播名、状态、标签、热度

按钮交互：

- 点击卡片主体 -> 进入直播间
- 点击主播头像 -> 进入主播主页
- 点击预约按钮 -> 设置提醒
- 点击关注按钮 -> 关注主播

状态说明：

- 直播中：展示 `直播中`
- 未开播：展示 `今晚 21:00` 或 `即将开播`
- 已预约：按钮变为 `已预约`

模块 C：主题直播入口

- 主题以宫格或横滑形式出现

按钮交互：

- 点击主题 -> 进入主题频道页

状态说明：

- 热门主题可显示小角标

模块 D：社区动态入口

- 每条动态显示头像、昵称、正文摘要、互动按钮

按钮交互：

- 点击动态主体 -> 进入动态详情
- 点击评论 -> 打开评论层
- 点击收藏 -> 收藏
- 点击头像 -> 进入用户主页

状态说明：

- 已点赞高亮
- 已收藏高亮

模块 E：创作者推荐

按钮交互：

- 点击主播卡 -> 进入主播主页
- 点击关注 -> 关注
- 点击预约 -> 预约开播

#### 首页页面跳转

- 首页 -> 搜索页
- 首页 -> 活动页
- 首页 -> 消息页
- 首页 -> 直播间
- 首页 -> 主播主页
- 首页 -> 动态详情
- 首页 -> 主题频道页

### 10.2 社区页原型说明

#### 页面目标

- 让用户从“观看”进入“表达与互动”
- 让用户在不开播时段仍有停留理由

#### 页面模块与交互

模块 A：顶部 Tab

- 最新
- 热门
- 关注
- 同城
- 话题

按钮交互：

- 点击 Tab -> 切换内容流

模块 B：发布入口

- 输入框提示：`分享此刻的想法`
- 支持图片、短视频、预约信息

按钮交互：

- 点击发布入口 -> 进入发布页

模块 C：动态流

按钮交互：

- 点击正文/图片 -> 动态详情
- 点击点赞 -> 点赞

状态说明：

- 空状态：展示“还没有内容，去看看大家在聊什么”
- 无关注内容时，引导用户去关注推荐用户

#### 社区页面跳转

- 社区 -> 动态详情
- 社区 -> 话题页
- 社区 -> 发布页

### 10.5 钱包页原型说明

#### 页面结构

- 顶部资产卡
- 充值档位列表
- 充值说明
- 客服入口

#### 按钮与交互

- 点击档位卡片 -> 选中该档位
- 点击 `立即充值` -> 发起支付流程
- 点击 `流水记录` -> 进入流水页
- 点击 `充值说明` -> 打开说明弹层

#### 状态说明

- 默认选中推荐档位
- 支付成功 -> 跳转成功提示页
- 支付失败 -> 弹出失败提示并支持重试

### 10.6 会员页原型说明

#### 页面结构

- 顶部会员卡
- 权益列表
- 升级说明
- 开通按钮

#### 按钮与交互

- 点击权益项 -> 查看详情
- 点击 `开通会员` -> 发起支付
- 点击 `升级会员` -> 进入升级流程

#### 状态说明

- 未开通：显示 `开通会员`
- 已开通：显示到期时间和升级入口

### 10.7 通用状态设计说明

所有核心页面应统一支持以下状态：

- 默认状态
- 加载中状态
- 空状态
- 错误状态
- 未登录状态

示例：

- 空状态：给出轻引导，不使用消极语气
- 错误状态：支持刷新重试
- 未登录状态：支持快捷登录引导

```text
用户进入 App
  ->
首页
  ->
查看推荐内容 / 主题入口 / 社区动态

选择一个动作
  ->
1. 进入直播间

3. 进入主题频道
4. 进入动态详情
5. 点击搜索
6. 点击活动
7. 点击消息
```

```text
首页
  ->

  ->
直播间
```
