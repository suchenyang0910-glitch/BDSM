## 三、Trae 候选代码：本轮拒绝合并原因

候选工作区完整测试结果：`153 tests / 147 pass / 6 fail`。

1. `server/src/routes/playback.ts` 存在 CommonJS `require()` 及 `.dbg` 调试上报；服务端 ESM 下播放会话、心跳、撤权会返回 500。
2. `h5/app.js` 向 `127.0.0.1:7777` 上报会话、清单和播放器错误；必须删除，不能作为正式埋点。
3. `telegramPublisher.ts` 在 Redis 启用时用 `require("bullmq")`，需改为 ESM 安全动态导入并补测试。
4. 视频发布回归没有同步“免费流量入口封面必发”规则。
5. 续费后端可顺延，但 H5/Mini App 尚无完整续费操作入口。

## 四、下一次放行门槛

1. 删除调试目录、调试 HTTP 上报、硬编码本机端口及所有 `require()` 运行时陷阱。
2. `server npm test` 全绿；server typecheck/build、admin build、H5/Mini App 语法检查全部通过。
3. 真实浏览器再次覆盖：桌面/手机首页、片库、详情、试看、试看结束、会员有效续费、到期续费、订单成功回流。
4. staging 覆盖：对象存储上传→转码→60 秒试看→有效权益完整播放→撤权立即拒绝。
5. staging 覆盖：免费流量入口默认推广发布、幂等重试、渠道归因、订单/权益/播放的漏斗闭环。

完成以上所有项后，才可由验收人签字合并候选分支，并部署生产。
